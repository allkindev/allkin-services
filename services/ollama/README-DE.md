# Ollama

Die Modelle auf deiner eigenen Maschine über die lokale API von Ollama.

## Nichts einzugeben

Kein Schlüssel. Die Adresse ist `http://localhost:11434` auf der Maschine, auf der Ollama läuft (oder ihr Name im Netz; Ollama muss darauf lauschen: `OLLAMA_HOST=0.0.0.0`).

## Gut zu wissen

Ein Modell herunterzuladen wiegt Gigabytes, eines zu löschen fragt nach deiner Bestätigung. Antworten sind bei großen Modellen langsam: Gib dem Agenten Zeit.

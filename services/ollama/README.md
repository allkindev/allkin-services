# Ollama

The models running on your own machine, through Ollama's local API.

## Nothing to enter

No key. The address is `http://localhost:11434` on the machine where Ollama runs (or its name on your network; Ollama must listen on it: `OLLAMA_HOST=0.0.0.0`).

## Good to know

Downloading a model weighs gigabytes and deleting one asks for your confirmation. Answers are slow on a big model: give the agent time.

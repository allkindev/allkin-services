# Ollama

Les modèles qui tournent sur ta propre machine, par l'API locale d'Ollama.

## Rien à saisir

Pas de clé. L'adresse est `http://localhost:11434` sur la machine où tourne Ollama (ou son nom sur ton réseau ; Ollama doit y écouter : `OLLAMA_HOST=0.0.0.0`).

## Bon à savoir

Télécharger un modèle pèse des gigaoctets et en supprimer un demande ta confirmation. Les réponses sont lentes sur un gros modèle : laisse du temps à l'agent.

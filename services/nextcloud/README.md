# Nextcloud

Files through WebDAV, shares, search, calendars and contacts.

## The account

Your login and an **application password**: **Settings → Security → Devices &
sessions → Create new app password**. Never your real password: an app
password is revoked alone. The address is the root of your Nextcloud.

## Good to know

Listing a folder uses the PROPFIND method, which the agent may use. Deleting
a file or a share asks for your confirmation.

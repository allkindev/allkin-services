# Nextcloud

Dateien über WebDAV, Freigaben, Suche, Kalender und Kontakte.

## Das Konto

Dein Benutzername und ein **App-Passwort**: **Einstellungen → Sicherheit →
Geräte & Sitzungen → Neues App-Passwort erstellen**. Nie dein echtes Passwort:
Ein App-Passwort lässt sich einzeln widerrufen. Die Adresse ist die Wurzel
deiner Nextcloud.

## Gut zu wissen

Das Auflisten eines Ordners nutzt die Methode PROPFIND, die der Agent
verwenden darf. Das Löschen einer Datei oder Freigabe fragt nach deiner
Bestätigung.

# Nextcloud

Archivos por WebDAV, compartidos, búsqueda, calendarios y contactos.

## La cuenta

Tu usuario y una **contraseña de aplicación**: **Ajustes → Seguridad →
Dispositivos y sesiones → Crear nueva contraseña de aplicación**. Nunca tu
contraseña real: una contraseña de aplicación se revoca sola. La dirección es
la raíz de tu Nextcloud.

## Conviene saber

Listar una carpeta usa el método PROPFIND, que el agente sabe usar. Eliminar un
archivo o un compartido pide tu confirmación.

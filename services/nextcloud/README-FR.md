# Nextcloud

Fichiers par WebDAV, partages, recherche, agendas et contacts.

## Le compte

Ton identifiant et un **mot de passe d'application** : **Paramètres →
Sécurité → Appareils et sessions → Créer un nouveau mot de passe
d'application**. Jamais ton vrai mot de passe : un mot de passe d'application
se révoque seul. L'adresse est la racine de ton Nextcloud.

## Bon à savoir

Lister un dossier passe par la méthode PROPFIND, que l'agent sait utiliser.
Supprimer un fichier ou un partage demande ta confirmation.

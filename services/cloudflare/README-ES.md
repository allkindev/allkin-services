# Cloudflare

Registros DNS, zonas, caché, ajustes, Workers y túneles.

## El token

**My Profile → API Tokens → Create Token**, desde una plantilla («Edit zone DNS») o a medida, limitado a las zonas que el agente debe tocar. Nunca la Global API Key.

## Conviene saber

Eliminar, cambiar un ajuste de zona y purgar la caché piden tu confirmación. Este servicio es distinto de Workers AI, que tiene su propia entrada.

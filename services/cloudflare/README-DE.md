# Cloudflare

DNS-Einträge, Zonen, Cache, Einstellungen, Workers und Tunnel.

## Das Token

**My Profile → API Tokens → Create Token**, aus einer Vorlage („Edit zone DNS“) oder maßgeschneidert, beschränkt auf die Zonen, die der Agent berühren soll. Niemals der Global API Key.

## Gut zu wissen

Löschen, eine Zoneneinstellung ändern und den Cache leeren fragen nach deiner Bestätigung. Dieser Dienst ist von Workers AI getrennt, das einen eigenen Eintrag hat.

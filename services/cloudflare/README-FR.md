# Cloudflare

Enregistrements DNS, zones, cache, réglages, Workers et tunnels.

## Le jeton

**My Profile → API Tokens → Create Token**, depuis un modèle (« Edit zone DNS ») ou sur mesure, limité aux zones que l'agent doit toucher. Jamais la Global API Key.

## Bon à savoir

Supprimer, modifier un réglage de zone et purger le cache demandent ta confirmation. Ce service est distinct de Workers AI, qui a sa propre entrée.

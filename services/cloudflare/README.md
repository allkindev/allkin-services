# Cloudflare

DNS records, zones, cache, settings, Workers and tunnels.

## The token

**My Profile → API Tokens → Create Token**, from a template ("Edit zone DNS") or custom, limited to the zones the agent should touch. Never the Global API Key.

## Good to know

Deleting, changing a zone setting and purging the cache ask for your confirmation. This service is separate from Workers AI, which has its own entry.

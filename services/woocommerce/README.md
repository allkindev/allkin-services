# WooCommerce

Orders, products, stock, customers, coupons and sales reports of a shop.

## The keys

**WooCommerce → Settings → Advanced → REST API → Add key**: pick the user,
the permissions (Read, or Read/Write), and copy the **consumer key** as the
login and the **consumer secret** as the password. Enter the shop's domain:
the REST address is built from it.

## Good to know

The keys are only safe over HTTPS: Allkin builds an `https://` address. A
refund and any deletion ask for your confirmation.

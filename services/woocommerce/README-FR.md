# WooCommerce

Commandes, produits, stock, clients, coupons et rapports de vente d'une
boutique.

## Les clés

**WooCommerce → Réglages → Avancé → API REST → Ajouter une clé** : choisis
l'utilisateur, les droits (lecture, ou lecture/écriture), et copie la
**consumer key** comme identifiant et le **consumer secret** comme mot de
passe. Saisis le domaine de la boutique : l'adresse REST en découle.

## Bon à savoir

Les clés ne sont sûres qu'en HTTPS : Allkin construit une adresse
`https://`. Un remboursement et toute suppression demandent ta confirmation.

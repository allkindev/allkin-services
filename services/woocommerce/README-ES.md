# WooCommerce

Pedidos, productos, stock, clientes, cupones e informes de ventas de una
tienda.

## Las claves

**WooCommerce → Ajustes → Avanzado → API REST → Añadir clave**: elige el
usuario, los permisos (lectura, o lectura/escritura), y copia la **consumer
key** como usuario y el **consumer secret** como contraseña. Introduce el
dominio de la tienda: la dirección REST se construye a partir de él.

## Conviene saber

Las claves solo son seguras por HTTPS: Allkin construye una dirección
`https://`. Un reembolso y cualquier eliminación piden tu confirmación.

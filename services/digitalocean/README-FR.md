# DigitalOcean

Droplets, domaines, App Platform, bases de données, volumes, pare-feu, solde.

## Le jeton

**API → Tokens → Generate New Token**, avec une expiration et les portées dont l'agent a besoin (lecture seule est un choix possible).

## Bon à savoir

Créer un droplet coûte, agir sur l'un (alimentation, redémarrage, instantané) et supprimer demandent ta confirmation.

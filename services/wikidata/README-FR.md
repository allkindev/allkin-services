# Wikidata

La base de connaissances structurée derrière Wikipédia : entités, propriétés,
et un point d'accès SPARQL pour les questions qui portent sur beaucoup d'éléments.

## Rien à saisir

Pas de clé. Le test cherche « Earth » et attend une entité en retour.

## Bon à savoir

Les requêtes SPARQL répondent sur `query.wikidata.org`, que l'agent peut joindre
par ce service. Les requêtes longues expirent après une minute : l'agent a pour
consigne de les garder petites.

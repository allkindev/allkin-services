# Wikidata

The structured knowledge base behind Wikipedia: entities, properties, and a
SPARQL endpoint for questions that span many items.

## Nothing to enter

No key. The test looks up "Earth" and expects an entity in return.

## Good to know

SPARQL queries answer on `query.wikidata.org`, which the agent may reach
through this service. Long queries time out after a minute: the agent is told
to keep them small.

# Wikidata

La base de conocimiento estructurada detrás de Wikipedia: entidades,
propiedades y un punto de acceso SPARQL para preguntas sobre muchos elementos.

## Nada que introducir

Sin clave. La prueba busca «Earth» y espera una entidad a cambio.

## Conviene saber

Las consultas SPARQL responden en `query.wikidata.org`, al que el agente puede
acceder por este servicio. Las consultas largas caducan al cabo de un minuto:
el agente tiene la consigna de mantenerlas pequeñas.

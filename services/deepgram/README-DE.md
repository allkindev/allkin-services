# Deepgram

Transkription von Audio per URL, Sprachsynthese, Textanalyse.

## Der Schlüssel

**<https://console.deepgram.com>** → ein Projekt → **API Keys → Create a New API Key**.

## Gut zu wissen

Das zu transkribierende Audio muss per URL erreichbar sein: Eine Datei auf der Festplatte des Agenten geht nicht über dieses Relais. Gib ihm einen Link (eine Cloud-Datei, eine Aufnahme auf einem Server).

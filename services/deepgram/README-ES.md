# Deepgram

Transcripción de audio por URL, síntesis de voz, análisis de texto.

## La clave

**<https://console.deepgram.com>** → un proyecto → **API Keys → Create a New API Key**.

## Conviene saber

El audio a transcribir debe ser accesible por URL: un archivo en el disco del agente no puede enviarse por este relevo. Dale un enlace (un archivo en la nube, una grabación en un servidor).

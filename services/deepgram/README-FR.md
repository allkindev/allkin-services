# Deepgram

Transcription d'audio par URL, synthèse vocale, analyse de texte.

## La clé

**<https://console.deepgram.com>** → un projet → **API Keys → Create a New API Key**.

## Bon à savoir

L'audio à transcrire doit être joignable par URL : un fichier sur le disque de l'agent ne peut pas partir par ce relais. Donne-lui un lien (un fichier dans le cloud, un enregistrement sur un serveur).

# Deepgram

Transcription of audio by URL, speech synthesis, text intelligence.

## The key

**<https://console.deepgram.com>** → a project → **API Keys → Create a New API Key**.

## Good to know

The audio to transcribe must be reachable by URL: a file on the agent's disk cannot be sent through this relay. Give it a link (a cloud file, a recording on a server).

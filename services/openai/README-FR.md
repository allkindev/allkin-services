# OpenAI

Chat, embeddings, images et voix par l'API d'OpenAI.

## La clé

**<https://platform.openai.com/api-keys>** → **Create new secret key** (`sk-…`), idéalement dans un projet à part avec un plafond de dépense.

## Bon à savoir

C'est pour un agent qui appelle OpenAI comme un outil (un second avis, une image, une voix) ; le moteur de l'agent lui-même se règle dans les Paramètres. Chaque appel est facturé.

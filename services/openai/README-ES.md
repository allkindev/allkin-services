# OpenAI

Chat, embeddings, imágenes y voz a través de la API de OpenAI.

## La clave

**<https://platform.openai.com/api-keys>** → **Create new secret key** (`sk-…`), idealmente en un proyecto aparte con un límite de gasto.

## Conviene saber

Es para un agente que llama a OpenAI como herramienta (una segunda opinión, una imagen, una voz); el motor del propio agente se configura en Ajustes. Cada llamada se factura.

# OpenAI

Chat, Embeddings, Bilder und Sprache über die API von OpenAI.

## Der Schlüssel

**<https://platform.openai.com/api-keys>** → **Create new secret key** (`sk-…`), am besten in einem eigenen Projekt mit Ausgabenlimit.

## Gut zu wissen

Das ist für einen Agenten, der OpenAI als Werkzeug aufruft (eine zweite Meinung, ein Bild, eine Stimme); der Motor des Agenten selbst wird in den Einstellungen gesetzt. Jeder Aufruf wird berechnet.

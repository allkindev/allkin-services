# Resend

Transaktionsmails von deinen verifizierten Domains, Zielgruppen und Aussendungen.

## Der Schlüssel

**<https://resend.com/api-keys>** → **Create API Key**, nur senden, wenn der Agent nur sendet.

## Gut zu wissen

Eine Mail oder Aussendung zu senden fragt nach deiner Bestätigung. Der Absender muss auf einer in Resend verifizierten Domain liegen.

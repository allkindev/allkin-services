# Resend

Correos transaccionales desde tus dominios verificados, audiencias y difusiones.

## La clave

**<https://resend.com/api-keys>** → **Create API Key**, solo envío si el agente solo envía.

## Conviene saber

Enviar un correo o una difusión pide tu confirmación. El remitente debe estar en un dominio verificado en Resend.

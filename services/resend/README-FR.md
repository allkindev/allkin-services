# Resend

Mails transactionnels depuis tes domaines vérifiés, audiences et diffusions.

## La clé

**<https://resend.com/api-keys>** → **Create API Key**, en envoi seul si l'agent ne fait qu'envoyer.

## Bon à savoir

Envoyer un mail ou une diffusion demande ta confirmation. L'expéditeur doit être sur un domaine vérifié dans Resend.

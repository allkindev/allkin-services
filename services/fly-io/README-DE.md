# Fly.io

Apps und Maschinen über die Machines API: Zustand, Start und Stopp, Erstellung, Volumes.

## Das Token

Ein Token aus dem Dashboard (**Tokens → Create**: ein Org-Token oder ein auf eine App beschränktes Deploy-Token), oder `fly tokens create org`.

## Gut zu wissen

Eine Maschine zu erstellen kostet, solange sie existiert: Es fragt nach deiner Bestätigung, wie Löschen. Logs sind nicht in dieser API.

# Fly.io

Applications et machines par l'API Machines : état, démarrage et arrêt, création, volumes.

## Le jeton

Un jeton depuis le tableau de bord (**Tokens → Create** : un jeton d'organisation, ou un jeton de déploiement limité à une application), ou `fly tokens create org`.

## Bon à savoir

Créer une machine coûte tant qu'elle existe : ça demande ta confirmation, comme supprimer. Les journaux ne sont pas dans cette API.

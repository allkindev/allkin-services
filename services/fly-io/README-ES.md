# Fly.io

Aplicaciones y máquinas a través de la API Machines: estado, arranque y parada, creación, volúmenes.

## El token

Un token desde el panel (**Tokens → Create**: un token de organización, o un token de despliegue limitado a una aplicación), o `fly tokens create org`.

## Conviene saber

Crear una máquina cuesta mientras exista: pide tu confirmación, como eliminar. Los registros no están en esta API.

# Pi-hole

Bloqueo DNS de anuncios (Pi-hole v6): estadísticas, dominios y clientes más
vistos, listas, pausa del bloqueo.

## La cuenta

La contraseña de la interfaz web (o una contraseña de aplicación creada en
**Settings → Web interface / API**, preferible: se revoca sola). El campo
nombre es libre: Pi-hole solo tiene una contraseña. La dirección es la de la
interfaz web, sin `/admin`.

## Conviene saber

Pi-hole v5 tiene otra API y no funcionará aquí. Pausar el bloqueo y quitar un
dominio o una lista piden tu confirmación.

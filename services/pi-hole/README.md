# Pi-hole

DNS ad blocking (Pi-hole v6): statistics, top domains and clients, lists,
pausing the blocking.

## The account

The password of the web interface (or an application password created in
**Settings → Web interface / API**, which is better: it can be revoked alone).
The name field is free: Pi-hole has a single password. The address is the one
of the web interface, without `/admin`.

## Good to know

Pi-hole v5 has a different API and will not work here. Pausing the blocking
and removing a domain or a list ask for your confirmation.

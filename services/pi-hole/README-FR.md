# Pi-hole

Blocage DNS des publicités (Pi-hole v6) : statistiques, domaines et clients
les plus vus, listes, mise en pause du blocage.

## Le compte

Le mot de passe de l'interface web (ou un mot de passe d'application créé dans
**Settings → Web interface / API**, préférable : il se révoque seul). Le champ
nom est libre : Pi-hole n'a qu'un mot de passe. L'adresse est celle de
l'interface web, sans `/admin`.

## Bon à savoir

Pi-hole v5 a une autre API et ne marchera pas ici. Mettre le blocage en pause
et retirer un domaine ou une liste demandent ta confirmation.

# Pi-hole

DNS-Werbeblocker (Pi-hole v6): Statistiken, häufigste Domains und Clients,
Listen, Pausieren der Blockierung.

## Das Konto

Das Passwort der Weboberfläche (oder ein Anwendungspasswort aus **Settings →
Web interface / API**, besser: Es lässt sich einzeln widerrufen). Das
Namensfeld ist frei: Pi-hole hat nur ein Passwort. Die Adresse ist die der
Weboberfläche, ohne `/admin`.

## Gut zu wissen

Pi-hole v5 hat eine andere API und funktioniert hier nicht. Das Pausieren der
Blockierung und das Entfernen einer Domain oder Liste fragen nach deiner
Bestätigung.

# Hugging Face

Der Hub: Modelle, Datensätze und Spaces suchen, ihre Karten und Dateien lesen.

## Der Schlüssel

**<https://huggingface.co/settings/tokens>** → **Create new token**, nur lesen reicht für den Hub.

## Gut zu wissen

Inferenz (ein Modell ausführen) liegt auf einem anderen Host, den dieser Dienst nicht erreicht: Nimm dafür OpenAI, Mistral oder OpenRouter, oder den generischen API-Eintrag auf `https://router.huggingface.co` mit demselben Token.

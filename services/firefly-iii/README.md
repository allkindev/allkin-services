# Firefly III

Accounts, transactions, budgets, bills, summaries.

## The token

A personal access token: **Profile → OAuth → Personal Access Tokens → Create
New Token**. The OAuth tab only shows when Firefly III is reached over HTTPS,
or when `APP_URL` matches the address you use. The address is the root of
your Firefly III.

## Good to know

Amounts travel as strings and dates as `YYYY-MM-DD`. Deleting a transaction
or an account asks for your confirmation.

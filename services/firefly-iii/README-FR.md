# Firefly III

Comptes, transactions, budgets, factures, synthèses.

## Le jeton

Un jeton d'accès personnel : **Profil → OAuth → Personal Access Tokens →
Create New Token**. L'onglet OAuth n'apparaît que si Firefly III est joint en
HTTPS, ou si `APP_URL` correspond à l'adresse que tu utilises. L'adresse est
la racine de ton Firefly III.

## Bon à savoir

Les montants voyagent en chaînes et les dates en `AAAA-MM-JJ`. Supprimer une
transaction ou un compte demande ta confirmation.

# Firefly III

Cuentas, transacciones, presupuestos, facturas, resúmenes.

## El token

Un token de acceso personal: **Perfil → OAuth → Personal Access Tokens →
Create New Token**. La pestaña OAuth solo aparece si Firefly III se alcanza por
HTTPS, o si `APP_URL` coincide con la dirección que usas. La dirección es la
raíz de tu Firefly III.

## Conviene saber

Los importes viajan como cadenas y las fechas como `AAAA-MM-DD`. Eliminar una
transacción o una cuenta pide tu confirmación.

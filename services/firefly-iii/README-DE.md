# Firefly III

Konten, Transaktionen, Budgets, Rechnungen, Zusammenfassungen.

## Das Token

Ein persönliches Zugriffstoken: **Profil → OAuth → Personal Access Tokens →
Create New Token**. Der OAuth-Reiter erscheint nur, wenn Firefly III über HTTPS
erreicht wird oder `APP_URL` der genutzten Adresse entspricht. Die Adresse ist
die Wurzel deines Firefly III.

## Gut zu wissen

Beträge reisen als Zeichenketten, Daten als `JJJJ-MM-TT`. Das Löschen einer
Transaktion oder eines Kontos fragt nach deiner Bestätigung.

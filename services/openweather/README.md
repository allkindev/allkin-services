# OpenWeather

Current weather and forecasts.

## The key

**<https://openweathermap.org>** → your account → **API keys**.

A new key takes **up to two hours** to become active. A `401` right after
signing up is therefore not a typo: it is too early.

## Good to know

The free tier covers current weather and five-day forecasts, up to sixty calls
per minute. The "One Call" and historical APIs require a subscription — an agent
getting a `401` on those has a valid key but the wrong plan.

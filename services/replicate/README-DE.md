# Replicate

Jedes öffentliche Modell (Bild, Audio, Video, Sprache) per Name ausführen und das Ergebnis lesen.

## Der Schlüssel

**<https://replicate.com/account/api-tokens>** → **Create token**.

## Gut zu wissen

Ein Lauf wird sekundengenau berechnet: Ihn zu starten fragt nach deiner Bestätigung. Ergebnisse sind oft URLs von Dateien im Speicher von Replicate, die der Agent dir als Links gibt.

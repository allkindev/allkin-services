# Mailchimp

Audiencias y sus miembros, etiquetas, campañas y sus informes.

## La clave

**Account → Extras → API keys → Create A Key**. La clave termina en `-us21` (u otro código): ese código es el **centro de datos** a introducir; cualquier nombre sirve como usuario, la clave es la contraseña.

## Conviene saber

Enviar una campaña va a toda su audiencia de golpe: pide tu confirmación, como eliminar. Los miembros se designan por el MD5 de su correo en minúsculas, que el agente calcula.

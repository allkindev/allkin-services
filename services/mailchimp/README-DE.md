# Mailchimp

Zielgruppen und ihre Mitglieder, Tags, Kampagnen und ihre Berichte.

## Der Schlüssel

**Account → Extras → API keys → Create A Key**. Der Schlüssel endet auf `-us21` (oder einen anderen Code): Dieser Code ist das einzutragende **Rechenzentrum**; ein beliebiger Name dient als Benutzername, der Schlüssel ist das Passwort.

## Gut zu wissen

Eine Kampagne zu senden geht auf einmal an das ganze Publikum: Es fragt nach deiner Bestätigung, wie Löschen. Mitglieder werden über den MD5 ihrer kleingeschriebenen E-Mail angesprochen, den der Agent berechnet.

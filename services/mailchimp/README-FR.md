# Mailchimp

Audiences et leurs membres, étiquettes, campagnes et leurs rapports.

## La clé

**Account → Extras → API keys → Create A Key**. La clé finit par `-us21` (ou un autre code) : ce code est le **centre de données** à saisir ; n'importe quel nom sert d'identifiant, la clé est le mot de passe.

## Bon à savoir

Envoyer une campagne part à toute son audience d'un coup : ça demande ta confirmation, comme supprimer. Les membres sont désignés par le MD5 de leur e-mail en minuscules, que l'agent calcule.

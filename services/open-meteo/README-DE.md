# Open-Meteo

Wetter, Vorhersagen, Verlauf und Luftqualität – kostenlos, ohne Schlüssel.

## Nichts einzugeben

Die Verbindung muss nur gespeichert werden: Der Test ruft die Vorhersage für
Paris ab, und das genügt als Beweis, dass der Dienst antwortet.

## Gut zu wissen

Der kostenlose Dienst ist für nicht-kommerzielle Nutzung gedacht, unter
zehntausend Aufrufen pro Tag. Jede Datenfamilie hat ihren eigenen Host
(Geocoding, Archiv, Luftqualität, Marine): Der Agent weiß das bereits.

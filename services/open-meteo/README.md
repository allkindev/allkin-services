# Open-Meteo

Weather, forecasts, history and air quality — free, without any key.

## Nothing to enter

The connection only needs to be saved: the test calls the forecast for Paris
and that is enough to prove the service answers.

## Good to know

The free service is meant for non-commercial use, under ten thousand calls a
day. Each family of data lives on its own host (geocoding, archive, air
quality, marine): the agent is already told which.

# Open-Meteo

Météo, prévisions, historique et qualité de l'air — gratuit, sans aucune clé.

## Rien à saisir

La connexion n'a qu'à être enregistrée : le test demande la prévision pour
Paris, ce qui suffit à prouver que le service répond.

## Bon à savoir

Le service gratuit est réservé à un usage non commercial, sous dix mille appels
par jour. Chaque famille de données a son propre hôte (géocodage, archives,
qualité de l'air, marine) : l'agent le sait déjà.

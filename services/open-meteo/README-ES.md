# Open-Meteo

Tiempo, previsiones, histórico y calidad del aire: gratis, sin ninguna clave.

## Nada que introducir

Basta con guardar la conexión: la prueba pide la previsión para París, lo que
demuestra que el servicio responde.

## Conviene saber

El servicio gratuito está reservado a un uso no comercial, por debajo de diez
mil llamadas al día. Cada familia de datos tiene su propio host (geocodificación,
archivo, calidad del aire, marino): el agente ya lo sabe.

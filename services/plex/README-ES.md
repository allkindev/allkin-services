# Plex

Tu Plex Media Server: bibliotecas, novedades, reproducciones en curso.

## El token

En Plex Web, abre cualquier elemento → **⋯ → Obtener información → Ver XML**:
la dirección termina con `X-Plex-Token=…`, ese es el valor. La dirección del
servidor es `http://host:32400`.

## Conviene saber

El token está ligado a tu cuenta de Plex: abre todos los servidores de la
cuenta. Eliminar un medio pide tu confirmación.

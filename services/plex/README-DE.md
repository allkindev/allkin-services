# Plex

Dein Plex Media Server: Bibliotheken, Neuzugänge, laufende Wiedergaben.

## Das Token

In Plex Web ein beliebiges Element öffnen → **⋯ → Info abrufen → XML
anzeigen**: Die Adresse endet mit `X-Plex-Token=…`, das ist der Wert. Die
Adresse des Servers ist `http://host:32400`.

## Gut zu wissen

Das Token hängt an deinem Plex-Konto: Es öffnet jeden Server des Kontos. Das
Löschen eines Mediums fragt nach deiner Bestätigung.

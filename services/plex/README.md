# Plex

Your Plex Media Server: libraries, what was added, what is playing.

## The token

In Plex Web, open any item → **⋯ → Get Info → View XML**: the address ends
with `X-Plex-Token=…`, that is the value. The address of the server is
`http://host:32400`.

## Good to know

The token is tied to your Plex account: it opens every server of the account.
Deleting a media item asks for your confirmation.

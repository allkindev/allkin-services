# Plex

Ton Plex Media Server : bibliothèques, nouveautés, lectures en cours.

## Le jeton

Dans Plex Web, ouvre n'importe quel élément → **⋯ → Obtenir des infos →
Afficher le XML** : l'adresse se termine par `X-Plex-Token=…`, c'est la valeur.
L'adresse du serveur est `http://hôte:32400`.

## Bon à savoir

Le jeton est lié à ton compte Plex : il ouvre tous les serveurs du compte.
Supprimer un média demande ta confirmation.

# Trello

Tableros, listas, tarjetas, checklists y comentarios.

## La clave y el token

Trello quiere dos valores. **<https://trello.com/power-ups/admin>** → crea un Power-Up (nombre libre) → **API key**: pégala en el campo *Clave de API*. Al lado, **Token**: genéralo y pégalo como secreto.

## Conviene saber

El token actúa en tu nombre en todos los tableros que ves. Eliminar y cerrar un tablero piden tu confirmación.

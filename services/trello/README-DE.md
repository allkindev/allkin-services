# Trello

Boards, Listen, Karten, Checklisten und Kommentare.

## Schlüssel und Token

Trello will zwei Werte. **<https://trello.com/power-ups/admin>** → ein Power-Up anlegen (beliebiger Name) → **API key**: in das Feld *API-Schlüssel* einfügen. Daneben **Token**: erzeugen und als Geheimnis einfügen.

## Gut zu wissen

Das Token handelt in deinem Namen auf jedem Board, das du siehst. Löschen und ein Board schließen fragen nach deiner Bestätigung.

# Trello

Tableaux, listes, cartes, checklists et commentaires.

## La clé et le jeton

Trello veut deux valeurs. **<https://trello.com/power-ups/admin>** → crée un Power-Up (nom libre) → **API key** : colle-la dans le champ *Clé d'API*. À côté, **Token** : génère-le et colle-le comme secret.

## Bon à savoir

Le jeton agit en ton nom sur tous les tableaux que tu vois. Supprimer et fermer un tableau demandent ta confirmation.

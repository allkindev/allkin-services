# Immich

Fotos und Videos: Alben, Suche nach Datum, Ort oder Inhalt, Personen.

## Der Schlüssel

In Immich: **Kontomenü → Kontoeinstellungen → API-Schlüssel → Neuer
Schlüssel**. Gib ihm nur die Rechte, die der Agent braucht (Lesen von Alben
und Medien, oder alles). Die Adresse ist die der Weboberfläche.

## Gut zu wissen

Das Löschen von Fotos oder Alben fragt nach deiner Bestätigung. Uploads laufen
ebenfalls über die API, wiegen aber, was sie wiegen: Der Agent sendet Dateien,
keine Worte.

# Immich

Photos and videos: albums, search by date, place or content, people.

## The key

In Immich: **account menu → Account Settings → API Keys → New API Key**. Give
it only the permissions the agent needs (reading albums and assets, or all).
The address is the one of the web interface.

## Good to know

Deleting photos or albums asks for your confirmation. Uploads go through the
API too but weigh what they weigh: the agent sends files, not words.

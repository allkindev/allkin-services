# Immich

Fotos y vídeos: álbumes, búsqueda por fecha, lugar o contenido, personas.

## La clave

En Immich: **menú de la cuenta → Ajustes de la cuenta → Claves API → Nueva
clave**. Dale solo los permisos que necesita el agente (lectura de álbumes y
medios, o todo). La dirección es la de la interfaz web.

## Conviene saber

Eliminar fotos o álbumes pide tu confirmación. Las subidas también pasan por
la API pero pesan lo que pesan: el agente envía archivos, no palabras.

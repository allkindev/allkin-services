# GitHub

Repositories, Issues, Pull Requests.

## Das Token erstellen

**Settings** → **Developer settings** → **Personal access tokens**.

Fine-grained Tokens sind vorzuziehen: Sie lassen sich auf ausgewählte
Repositories beschränken, während ein klassisches Token für dein ganzes Konto
gilt.

Gib ihm **so wenige Scopes wie möglich**. Ein Agent, der Issues liest, muss
keinen Code schreiben; ein Agent, der Pull Requests öffnet, muss nicht die
Organisation verwalten.

## Gut zu wissen

Das Token handelt in deinem Namen: Was der Agent schreibt, erscheint unter
deinem Namen und mit deinem Avatar. Um seine Arbeit von deiner zu unterscheiden,
lege ein Maschinenkonto an und nimm das Token von dort.

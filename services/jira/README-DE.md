# Jira

Vorgänge, Projekte, Boards und Sprints von Jira Cloud.

## Das Konto

Ein API-Token deines Atlassian-Kontos: **<https://id.atlassian.com/manage-profile/security/api-tokens>** → **Create API token**. Gib die E-Mail des Kontos als Benutzername und das Token als Passwort ein, dazu den Namen deiner Site (der Teil vor `.atlassian.net`).

## Gut zu wissen

Beschreibungen und Kommentare reisen im Atlassian Document Format, das der Agent kennt. Dasselbe Token dient für Confluence. Jira Server oder Data Center hat eine andere API (`/rest/api/2`, persönliches Token): Nimm dafür den generischen Eintrag.

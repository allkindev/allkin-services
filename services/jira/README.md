# Jira

Issues, projects, boards and sprints of Jira Cloud.

## The account

An API token of your Atlassian account: **<https://id.atlassian.com/manage-profile/security/api-tokens>** → **Create API token**. Enter your account email as the login and the token as the password, and the name of your site (the part before `.atlassian.net`).

## Good to know

Descriptions and comments travel in Atlassian Document Format, which the agent knows. The same token serves Confluence. Jira Server or Data Center has another API (`/rest/api/2`, a personal access token): use the generic entry for it.

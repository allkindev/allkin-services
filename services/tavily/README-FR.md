# Tavily

Recherche et extraction de pages faites pour les agents : les résultats
viennent avec une courte synthèse, et une page entière se lit en texte.

## La clé

**<https://app.tavily.com>** → connexion → **API Keys**. Les clés commencent
par `tvly-`. Le palier gratuit donne un crédit mensuel.

## Bon à savoir

Une recherche coûte un crédit par appel, une extraction un crédit pour quelques
pages ; l'agent a pour consigne de préférer une bonne requête à plusieurs. Le
test lit la consommation du compte, ce qui ne coûte rien.

# Tavily

Search and page extraction made for agents: results come with a short
synthesis, and whole pages can be read as text.

## The key

**<https://app.tavily.com>** → sign in → **API Keys**. Keys start with
`tvly-`. The free plan gives a monthly allowance of credits.

## Good to know

Search costs one credit per call, extraction one per few pages; the agent is
told to prefer one good query over many. The test reads the account's usage,
which is free.

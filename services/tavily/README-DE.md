# Tavily

Suche und Seitenextraktion für Agenten: Die Ergebnisse kommen mit einer kurzen
Zusammenfassung, und ganze Seiten lassen sich als Text lesen.

## Der Schlüssel

**<https://app.tavily.com>** → anmelden → **API Keys**. Schlüssel beginnen mit
`tvly-`. Der kostenlose Tarif gibt ein monatliches Guthaben.

## Gut zu wissen

Eine Suche kostet ein Guthaben pro Aufruf, eine Extraktion eines für wenige
Seiten; der Agent soll eine gute Abfrage mehreren vorziehen. Der Test liest
den Verbrauch des Kontos, was nichts kostet.

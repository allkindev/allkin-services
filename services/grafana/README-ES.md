# Grafana

Paneles, fuentes de datos y sus consultas, alertas, anotaciones.

## El token

**Administration → Users and access → Service accounts → Add service
account**, con el rol que necesita el agente (Viewer para leer), luego **Add
service account token**. La dirección es la de Grafana.

## Conviene saber

Guardar un panel lo reemplaza, y eliminar cualquier cosa pide tu
confirmación. Consultar una fuente de datos a través de Grafana funciona igual
para Prometheus, Loki y las fuentes SQL.

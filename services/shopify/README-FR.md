# Shopify

Commandes, expéditions, produits, stock et clients de ta boutique.

## L'application

Une application personnalisée dans la boutique : **Paramètres → Applications et canaux de vente → Développer des applications → Créer une application**, donne-lui les portées Admin API dont l'agent a besoin (read_orders, write_orders, read_products…), **Installer**, puis copie le **jeton d'accès Admin API** (affiché une seule fois). Saisis le nom de la boutique (la partie avant `.myshopify.com`).

## Bon à savoir

L'adresse porte la version de l'API (2026-01) ; Shopify garde une version un an. Remboursements, annulations et suppressions demandent ta confirmation.

# Shopify

Pedidos, envíos, productos, stock y clientes de tu tienda.

## La aplicación

Una aplicación personalizada en la tienda: **Configuración → Aplicaciones y canales de venta → Desarrollar aplicaciones → Crear una aplicación**, dale los ámbitos de Admin API que necesita el agente (read_orders, write_orders, read_products…), **Instalar**, luego copia el **token de acceso Admin API** (mostrado una sola vez). Introduce el nombre de la tienda (la parte antes de `.myshopify.com`).

## Conviene saber

La dirección lleva la versión de la API (2026-01); Shopify mantiene una versión un año. Reembolsos, cancelaciones y eliminaciones piden tu confirmación.

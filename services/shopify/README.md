# Shopify

Orders, fulfilment, products, stock and customers of your store.

## The application

A custom app in the store: **Settings → Apps and sales channels → Develop apps → Create an app**, give it the Admin API scopes the agent needs (read_orders, write_orders, read_products…), **Install app**, then copy the **Admin API access token** (shown once). Enter the store's name (the part before `.myshopify.com`).

## Good to know

The address carries the API version (2026-01); Shopify keeps a version a year. Refunds, cancellations and deletions ask for your confirmation.

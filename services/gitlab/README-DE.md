# GitLab

Projekte, Issues, Merge Requests, Pipelines und Dateien – auf gitlab.com oder deiner eigenen Instanz.

## Das Token

**Dein Avatar → Einstellungen → Zugriffstoken → Neues Token**, mit den Bereichen, die der Agent braucht (`read_api` zum Lesen, `api` zum Schreiben). Die Adresse ist `https://gitlab.com` oder die Wurzel deiner Instanz.

## Gut zu wissen

Ein Projekt-Token beschränkt den Agenten auf ein Projekt: die sicherere Wahl für einen Bot. Das Löschen eines Projekts fragt nach deiner Bestätigung und sagt, was es bedeutet.

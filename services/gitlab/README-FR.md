# GitLab

Projets, issues, merge requests, pipelines et fichiers — sur gitlab.com ou ta propre instance.

## Le jeton

**Ton avatar → Préférences → Jetons d'accès → Ajouter un jeton**, avec les portées dont l'agent a besoin (`read_api` pour lire, `api` pour écrire). L'adresse est `https://gitlab.com`, ou la racine de ton instance.

## Bon à savoir

Un jeton de projet limite l'agent à un seul projet : le choix le plus sûr pour un bot. Supprimer un projet demande ta confirmation et dit ce que ça implique.

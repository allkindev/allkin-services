# GitLab

Proyectos, issues, merge requests, pipelines y archivos: en gitlab.com o tu propia instancia.

## El token

**Tu avatar → Preferencias → Tokens de acceso → Añadir token**, con los ámbitos que necesita el agente (`read_api` para leer, `api` para escribir). La dirección es `https://gitlab.com`, o la raíz de tu instancia.

## Conviene saber

Un token de proyecto limita al agente a un solo proyecto: la opción más segura para un bot. Eliminar un proyecto pide tu confirmación y dice lo que implica.

# HubSpot

Contactos, empresas, negocios, tickets y notas de tu CRM.

## La aplicación

Una aplicación privada: **Configuración → Integraciones → Aplicaciones privadas → Crear una aplicación privada**, con los ámbitos que necesita el agente (crm.objects.contacts.read, …write, companies, deals), luego su **token de acceso**.

## Conviene saber

Eliminar pide tu confirmación. Las propiedades son los campos personalizados de tu portal: el agente puede listarlas antes de escribir.

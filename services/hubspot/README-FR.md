# HubSpot

Contacts, entreprises, affaires, tickets et notes de ton CRM.

## L'application

Une application privée : **Paramètres → Intégrations → Applications privées → Créer une application privée**, avec les portées dont l'agent a besoin (crm.objects.contacts.read, …write, companies, deals), puis son **jeton d'accès**.

## Bon à savoir

Supprimer demande ta confirmation. Les propriétés sont les champs personnalisés de ton portail : l'agent peut les lister avant d'écrire.

# HubSpot

Contacts, companies, deals, tickets and notes of your CRM.

## The application

A private app: **Settings → Integrations → Private Apps → Create a private app**, with the scopes the agent needs (crm.objects.contacts.read, …write, companies, deals), then its **access token**.

## Good to know

Deleting asks for your confirmation. Properties are the custom fields of your portal: the agent can list them before writing.

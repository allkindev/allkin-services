# HubSpot

Kontakte, Unternehmen, Deals, Tickets und Notizen deines CRM.

## Die Anwendung

Eine private App: **Einstellungen → Integrationen → Private Apps → Private App erstellen**, mit den nötigen Bereichen (crm.objects.contacts.read, …write, companies, deals), dann ihr **Zugriffstoken**.

## Gut zu wissen

Löschen fragt nach deiner Bestätigung. Eigenschaften sind die benutzerdefinierten Felder deines Portals: Der Agent kann sie vor dem Schreiben auflisten.

# ElevenLabs

Voces y síntesis de voz: el agente escribe, ElevenLabs habla, el audio aterriza en sus archivos.

## La clave

**<https://elevenlabs.io/app/settings/api-keys>** → **Create API Key**.

## Conviene saber

Cada carácter hablado cuenta en el plan. El agente guarda el audio como archivo (MP3) en lugar de leerlo.

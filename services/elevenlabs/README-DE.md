# ElevenLabs

Stimmen und Sprachsynthese: Der Agent schreibt, ElevenLabs spricht, das Audio landet in seinen Dateien.

## Der Schlüssel

**<https://elevenlabs.io/app/settings/api-keys>** → **Create API Key**.

## Gut zu wissen

Jedes gesprochene Zeichen zählt auf den Tarif. Der Agent speichert das Audio als Datei (MP3), statt es zu lesen.

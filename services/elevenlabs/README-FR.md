# ElevenLabs

Voix et synthèse vocale : l'agent écrit, ElevenLabs parle, l'audio atterrit dans ses fichiers.

## La clé

**<https://elevenlabs.io/app/settings/api-keys>** → **Create API Key**.

## Bon à savoir

Chaque caractère prononcé compte sur le forfait. L'agent enregistre l'audio en fichier (MP3) plutôt que de le lire.

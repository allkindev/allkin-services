# Vercel

Proyectos, despliegues y sus registros, variables de entorno, dominios.

## El token

**Account settings → Tokens → Create**, con un alcance (tu cuenta o un equipo) y una caducidad.

## Conviene saber

Las llamadas para un equipo necesitan `?teamId=` en cada petición; el agente lo sabe. Lanzar un despliegue y eliminar piden tu confirmación.

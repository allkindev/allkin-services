# Vercel

Projekte, Deployments und ihre Logs, Umgebungsvariablen, Domains.

## Das Token

**Account settings → Tokens → Create**, mit einem Geltungsbereich (dein Konto oder ein Team) und einem Ablauf.

## Gut zu wissen

Aufrufe für ein Team brauchen `?teamId=` bei jeder Anfrage; der Agent weiß das. Ein Deployment auszulösen und Löschen fragen nach deiner Bestätigung.

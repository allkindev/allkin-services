# Vercel

Projets, déploiements et leurs journaux, variables d'environnement, domaines.

## Le jeton

**Account settings → Tokens → Create**, avec une portée (ton compte ou une équipe) et une expiration.

## Bon à savoir

Les appels pour une équipe demandent `?teamId=` sur chaque requête ; l'agent le sait. Déclencher un déploiement et supprimer demandent ta confirmation.

# Scaleway

Instancias, almacenamiento de objetos, serverless, bases de datos gestionadas, facturación de Scaleway.

## La clave

**IAM → API keys → Generate an API key**, para una aplicación o un usuario, con un proyecto por defecto. Introduce la **clave secreta** (la clave de acceso no es necesaria).

## Conviene saber

La mayoría de las llamadas nombran una zona o región en su ruta; el agente conoce las habituales. Crear una instancia y eliminar piden tu confirmación. El almacenamiento de objetos en sí (S3) necesita sus propias claves.

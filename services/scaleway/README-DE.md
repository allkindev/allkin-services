# Scaleway

Instanzen, Objektspeicher, Serverless, verwaltete Datenbanken, Abrechnung von Scaleway.

## Der Schlüssel

**IAM → API keys → Generate an API key**, für eine Anwendung oder einen Benutzer, mit einem Standardprojekt. Gib den **Secret Key** ein (der Access Key wird nicht gebraucht).

## Gut zu wissen

Die meisten Aufrufe nennen eine Zone oder Region im Pfad; der Agent kennt die üblichen. Eine Instanz zu erstellen und Löschen fragen nach deiner Bestätigung. Der Objektspeicher selbst (S3) braucht eigene Schlüssel.

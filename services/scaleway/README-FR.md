# Scaleway

Instances, stockage objet, serverless, bases de données managées, facturation de Scaleway.

## La clé

**IAM → Clés d'API → Générer une clé d'API**, pour une application ou un utilisateur, avec un projet par défaut. Saisis la **clé secrète** (la clé d'accès n'est pas nécessaire).

## Bon à savoir

La plupart des appels nomment une zone ou une région dans leur chemin ; l'agent connaît les usuelles. Créer une instance et supprimer demandent ta confirmation. Le stockage objet lui-même (S3) demande ses propres clés.

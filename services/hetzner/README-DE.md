# Hetzner Cloud

Server, Volumes, Snapshots, Firewalls und Preise von Hetzner Cloud.

## Das Token

In der Cloud Console, in einem Projekt: **Security → API tokens → Generate API token** (Read nur zum Lesen, Read & Write zum Handeln). Ein Token pro Projekt.

## Gut zu wissen

Einen Server zu erstellen kostet; Strom abschalten, neu aufsetzen oder löschen verliert, was läuft oder auf der Festplatte ist. All das fragt nach deiner Bestätigung.

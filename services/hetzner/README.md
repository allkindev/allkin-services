# Hetzner Cloud

Servers, volumes, snapshots, firewalls and prices of Hetzner Cloud.

## The token

In the Cloud Console, in a project: **Security → API tokens → Generate API token** (Read for reading only, Read & Write to act). One token per project.

## Good to know

Creating a server costs money; cutting its power, rebuilding or deleting lose what runs or what is on the disk. All of these ask for your confirmation.

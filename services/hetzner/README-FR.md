# Hetzner Cloud

Serveurs, volumes, instantanés, pare-feu et prix de Hetzner Cloud.

## Le jeton

Dans la Cloud Console, dans un projet : **Security → API tokens → Generate API token** (Read pour lire seulement, Read & Write pour agir). Un jeton par projet.

## Bon à savoir

Créer un serveur coûte ; couper l'alimentation, réinstaller ou supprimer perdent ce qui tourne ou ce qui est sur le disque. Tout cela demande ta confirmation.

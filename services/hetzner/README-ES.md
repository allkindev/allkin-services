# Hetzner Cloud

Servidores, volúmenes, instantáneas, cortafuegos y precios de Hetzner Cloud.

## El token

En la Cloud Console, dentro de un proyecto: **Security → API tokens → Generate API token** (Read para solo leer, Read & Write para actuar). Un token por proyecto.

## Conviene saber

Crear un servidor cuesta; cortar la alimentación, reinstalar o eliminar pierden lo que corre o lo que hay en el disco. Todo eso pide tu confirmación.

# Mattermost

Teams, channels, messages, direct messages.

## The token

**Profile → Security → Personal Access Tokens → Create Token**. An
administrator must have enabled personal access tokens (**System Console →
Integrations → Integration Management**). The address is the root of your
Mattermost.

## Good to know

The token acts as you: what it posts is posted in your name. Deleting a
message or a channel asks for your confirmation.

# Mattermost

Teams, Kanäle, Nachrichten, Direktnachrichten.

## Das Token

**Profil → Sicherheit → Persönliche Zugriffstoken → Token erstellen**. Ein
Administrator muss persönliche Token aktiviert haben (**Systemkonsole →
Integrationen → Integrationsverwaltung**). Die Adresse ist die Wurzel deines
Mattermost.

## Gut zu wissen

Das Token handelt als du: Was es postet, wird in deinem Namen gepostet. Das
Löschen einer Nachricht oder eines Kanals fragt nach deiner Bestätigung.

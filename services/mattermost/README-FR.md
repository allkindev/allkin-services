# Mattermost

Équipes, canaux, messages, messages directs.

## Le jeton

**Profil → Sécurité → Jetons d'accès personnels → Créer un jeton**. Un
administrateur doit avoir activé les jetons personnels (**Console système →
Intégrations → Gestion des intégrations**). L'adresse est la racine de ton
Mattermost.

## Bon à savoir

Le jeton agit en ton nom : ce qu'il publie est publié par toi. Supprimer un
message ou un canal demande ta confirmation.

# Mattermost

Equipos, canales, mensajes, mensajes directos.

## El token

**Perfil → Seguridad → Tokens de acceso personal → Crear token**. Un
administrador debe haber activado los tokens personales (**Consola del
sistema → Integraciones → Gestión de integraciones**). La dirección es la raíz
de tu Mattermost.

## Conviene saber

El token actúa como tú: lo que publica se publica en tu nombre. Eliminar un
mensaje o un canal pide tu confirmación.

# Linear

Issues, Projekte, Teams und Kommentare über die GraphQL-API von Linear.

## Das Token

**Settings → Security & access → Personal API keys → Create key**. Er beginnt mit `lin_api_`.

## Gut zu wissen

Alles ist eine GraphQL-Abfrage an einen einzigen Endpunkt: Der Agent kennt die Formen für die üblichen Bedürfnisse (meine Issues, suchen, erstellen, kommentieren, Status ändern). Der Schlüssel handelt in deinem Namen.

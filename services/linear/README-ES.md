# Linear

Issues, proyectos, equipos y comentarios, a través de la API GraphQL de Linear.

## El token

**Settings → Security & access → Personal API keys → Create key**. Empieza por `lin_api_`.

## Conviene saber

Todo es una consulta GraphQL en un único punto de acceso: el agente conoce las formas de las necesidades habituales (mis issues, buscar, crear, comentar, cambiar de estado). La clave actúa en tu nombre.

# Linear

Issues, projets, équipes et commentaires, par l'API GraphQL de Linear.

## Le jeton

**Settings → Security & access → Personal API keys → Create key**. Elle commence par `lin_api_`.

## Bon à savoir

Tout est une requête GraphQL sur un seul point d'accès : l'agent connaît les formes des besoins courants (mes issues, chercher, créer, commenter, changer d'état). La clé agit en ton nom.

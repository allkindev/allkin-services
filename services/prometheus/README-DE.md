# Prometheus

Metriken und PromQL-Abfragen, sofort oder über einen Zeitraum.

## Nichts einzugeben

Prometheus hat keine eigene Authentifizierung: Die Adresse genügt. Steht
deines hinter einem Reverse-Proxy mit Passwort, nimm stattdessen den
generischen Eintrag „beliebige API mit Schlüssel“.

## Gut zu wissen

Eine Zeitraumabfrage kann viel liefern: Der Agent hält Zeiträume kurz und
Schritte grob. Die Zielseite sagt, welche Exporter antworten.

# Notion

Pages and databases.

## The integration

**<https://notion.so/my-integrations>** → **New integration**. The internal
secret it displays is the key to paste here.

## The step everyone misses

A fresh integration **sees nothing**, even with a valid key. You must explicitly
share the relevant pages with it: open the page in Notion, `•••` menu →
**Connections** → pick your integration.

This is also what bounds the agent: it will only ever see what you shared.
Sharing is inherited, so sharing a root page opens everything inside it — handy,
and worth knowing.

## Good to know

Search results only surface shared pages. An agent that "finds nothing" almost
always has a sharing problem, not a key problem.

# OpenRouter

Une clé pour des centaines de modèles de tous les fournisseurs, avec leurs prix.

## La clé

**<https://openrouter.ai/keys>** → **Create key**, avec un plafond de crédits si tu veux.

## Bon à savoir

Les identifiants de modèles sont `fournisseur/nom` ; l'agent peut les lister avec leurs prix et en choisir un gratuit (`:free`). C'est un outil pour l'agent, pas son propre moteur, qui se règle dans les Paramètres.

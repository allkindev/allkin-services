# OpenRouter

Ein Schlüssel für Hunderte Modelle aller Anbieter, mit ihren Preisen.

## Der Schlüssel

**<https://openrouter.ai/keys>** → **Create key**, auf Wunsch mit einem Guthabenlimit.

## Gut zu wissen

Modell-Ids sind `anbieter/name`; der Agent kann sie mit Preisen auflisten und ein kostenloses wählen (`:free`). Das ist ein Werkzeug für den Agenten, nicht sein eigener Motor, der in den Einstellungen gesetzt wird.

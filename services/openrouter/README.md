# OpenRouter

One key for hundreds of models from every provider, with their prices.

## The key

**<https://openrouter.ai/keys>** → **Create key**, with a credit limit if you like.

## Good to know

Model ids are `provider/name`; the agent can list them with their prices and pick a free one (`:free`). This is a tool for the agent, not its own engine, which is set in Settings.

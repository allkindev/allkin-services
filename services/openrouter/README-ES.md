# OpenRouter

Una clave para cientos de modelos de todos los proveedores, con sus precios.

## La clave

**<https://openrouter.ai/keys>** → **Create key**, con un límite de créditos si quieres.

## Conviene saber

Los identificadores de modelo son `proveedor/nombre`; el agente puede listarlos con sus precios y elegir uno gratuito (`:free`). Es una herramienta para el agente, no su propio motor, que se configura en Ajustes.

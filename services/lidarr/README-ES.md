# Lidarr

Música: artistas, álbumes, lo que falta, la cola de descargas.

## La clave

**Settings → General → Security → API Key** en la interfaz de Lidarr. La
dirección es la de la interfaz web (`http://host:puerto`), sin `/api`.

## Conviene saber

La API es la versión 1. Eliminar de la biblioteca y lanzar comandos piden tu confirmación
en la conversación.

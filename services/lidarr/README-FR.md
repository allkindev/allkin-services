# Lidarr

Musique : artistes, albums, ce qui manque, la file de téléchargement.

## La clé

**Settings → General → Security → API Key** dans l'interface de Lidarr.
L'adresse est celle de l'interface web (`http://hôte:port`), sans `/api`.

## Bon à savoir

L'API est en version 1. Supprimer de la bibliothèque et lancer des commandes demandent ta
confirmation dans la conversation.

# Lidarr

Musik: Künstler, Alben, was fehlt, die Download-Warteschlange.

## Der Schlüssel

**Settings → General → Security → API Key** in der Oberfläche von Lidarr. Die
Adresse ist die der Weboberfläche (`http://host:port`), ohne `/api`.

## Gut zu wissen

Die API ist Version 1. Löschen aus der Bibliothek und das Starten von Befehlen fragen
dich im Gespräch um Bestätigung.

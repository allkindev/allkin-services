# Confluence

Páginas, espacios y búsqueda de Confluence Cloud.

## La cuenta

El mismo que Jira: un token de API desde **<https://id.atlassian.com/manage-profile/security/api-tokens>**, el correo de la cuenta como usuario, el token como contraseña, y el nombre de tu sitio. Allkin añade `/wiki` a la dirección.

## Conviene saber

Actualizar una página reemplaza todo su contenido y exige su número de versión: el agente la lee primero, y pide tu confirmación.

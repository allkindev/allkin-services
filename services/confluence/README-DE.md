# Confluence

Seiten, Bereiche und Suche von Confluence Cloud.

## Das Konto

Dasselbe wie bei Jira: ein API-Token von **<https://id.atlassian.com/manage-profile/security/api-tokens>**, die E-Mail des Kontos als Benutzername, das Token als Passwort und der Name deiner Site. Allkin hängt `/wiki` an die Adresse.

## Gut zu wissen

Das Aktualisieren einer Seite ersetzt ihren ganzen Inhalt und braucht ihre Versionsnummer: Der Agent liest sie zuerst und fragt nach deiner Bestätigung.

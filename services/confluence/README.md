# Confluence

Pages, spaces and search of Confluence Cloud.

## The account

The same as Jira: an API token from **<https://id.atlassian.com/manage-profile/security/api-tokens>**, your account email as the login, the token as the password, and the name of your site. Allkin adds `/wiki` to the address.

## Good to know

Updating a page replaces its whole content and needs its version number: the agent reads it first, and asks for your confirmation.

# Deluge

Torrents über das JSON-RPC der Weboberfläche.

## Das Konto

Nur das Passwort der Weboberfläche zählt (`deluge` als Standard: ändern). Das
Namensfeld ist frei: Deluge hat keine Benutzerkonten.

## Gut zu wissen

Die Weboberfläche muss mit ihrem Daemon verbunden sein, damit Torrents
erscheinen: Der Agent prüft das und verbindet sich bei Bedarf mit dem lokalen
Daemon.

# Deluge

Torrents a través del JSON-RPC de la interfaz web.

## La cuenta

Solo cuenta la contraseña de la interfaz web (`deluge` por defecto: cámbiala).
El campo nombre es libre: Deluge no tiene cuentas de usuario.

## Conviene saber

La interfaz web debe estar conectada a su demonio para que aparezcan los
torrents: el agente lo comprueba y se conecta al demonio local si hace falta.

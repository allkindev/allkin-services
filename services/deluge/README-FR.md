# Deluge

Torrents par le JSON-RPC de l'interface web.

## Le compte

Seul le mot de passe de l'interface web compte (`deluge` par défaut : à
changer). Le champ nom est libre : Deluge n'a pas de comptes utilisateur.

## Bon à savoir

L'interface web doit être connectée à son démon pour que les torrents
apparaissent : l'agent le vérifie et se connecte au démon local au besoin.

# Attio

Personnes, entreprises, affaires, listes, notes et tâches de ton espace Attio.

## L'application

**Workspace settings → Developers → Create a new integration** → son **jeton d'accès**, avec les portées dont l'agent a besoin (record read/write, list, note).

## Bon à savoir

Supprimer demande ta confirmation. Chaque attribut d'une fiche est une liste de valeurs : l'agent lit la première.

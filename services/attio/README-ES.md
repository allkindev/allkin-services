# Attio

Personas, empresas, negocios, listas, notas y tareas de tu espacio Attio.

## La aplicación

**Workspace settings → Developers → Create a new integration** → su **token de acceso**, con los ámbitos que necesita el agente (record read/write, list, note).

## Conviene saber

Eliminar pide tu confirmación. Cada atributo de una ficha es una lista de valores: el agente lee el primero.

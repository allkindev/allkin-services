# Attio

Personen, Unternehmen, Deals, Listen, Notizen und Aufgaben deines Attio-Workspace.

## Die Anwendung

**Workspace settings → Developers → Create a new integration** → ihr **Zugriffstoken**, mit den nötigen Bereichen (record read/write, list, note).

## Gut zu wissen

Löschen fragt nach deiner Bestätigung. Jedes Attribut eines Datensatzes ist eine Liste von Werten: Der Agent liest den ersten.

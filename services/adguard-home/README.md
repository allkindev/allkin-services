# AdGuard Home

DNS ad blocking: statistics, query log, filters, clients, rewrites.

## The account

The login and password of the web interface. The address is the one of the
web interface (`http://host:80` or `:3000`).

## Good to know

Pausing the protection and changing the filtering rules ask for your
confirmation: the rules endpoint replaces the whole list, the agent reads it
first.

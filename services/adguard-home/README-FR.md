# AdGuard Home

Blocage DNS des publicités : statistiques, journal des requêtes, filtres,
clients, réécritures.

## Le compte

L'identifiant et le mot de passe de l'interface web. L'adresse est celle de
l'interface web (`http://hôte:80` ou `:3000`).

## Bon à savoir

Mettre la protection en pause et modifier les règles de filtrage demandent ta
confirmation : le point d'accès des règles remplace la liste entière, l'agent
la lit d'abord.

# AdGuard Home

Bloqueo DNS de anuncios: estadísticas, registro de consultas, filtros,
clientes, reescrituras.

## La cuenta

El usuario y la contraseña de la interfaz web. La dirección es la de la
interfaz web (`http://host:80` o `:3000`).

## Conviene saber

Pausar la protección y cambiar las reglas de filtrado piden tu confirmación:
el punto de acceso de las reglas reemplaza la lista entera, el agente la lee
antes.

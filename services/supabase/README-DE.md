# Supabase

Dein Supabase-Konto über die Management-API: Projekte, SQL auf ihren Datenbanken, Funktionen, Zustand.

## Das Token

**Account → Access Tokens → Generate new token** (`sbp_…`).

## Gut zu wissen

SQL über diese API auszuführen kann Daten ändern oder löschen: Jede Abfrage fragt nach deiner Bestätigung. Die API-Schlüssel eines Projekts sind Geheimnisse, die der Agent nicht wiederholen darf.

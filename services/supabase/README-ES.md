# Supabase

Tu cuenta de Supabase a través de la API de gestión: proyectos, SQL en sus bases, funciones, salud.

## El token

**Account → Access Tokens → Generate new token** (`sbp_…`).

## Conviene saber

Ejecutar SQL por esta API puede modificar o borrar datos: cada consulta pide tu confirmación. Las claves de API de un proyecto son secretos que el agente no debe repetir.

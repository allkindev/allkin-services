# Supabase

Ton compte Supabase par l'API de gestion : projets, SQL sur leurs bases, fonctions, santé.

## Le jeton

**Account → Access Tokens → Generate new token** (`sbp_…`).

## Bon à savoir

Exécuter du SQL par cette API peut modifier ou effacer des données : chaque requête demande ta confirmation. Les clés d'API d'un projet sont des secrets que l'agent ne doit pas répéter.

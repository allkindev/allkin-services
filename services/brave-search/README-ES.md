# Brave Search

Búsqueda web, de noticias e imágenes mediante la API de Brave Search.

## La clave

**<https://api-dashboard.search.brave.com>** → inicia sesión → **API Keys**. El
plan gratuito da una cuota de consultas al mes; puede pedirse una tarjeta para
abrirlo.

## Conviene saber

Cada llamada cuenta como una consulta del plan, sea cual sea su tamaño: el
agente tiene la consigna de buscar una vez con una buena consulta en lugar de
varias veces con consultas estrechas.

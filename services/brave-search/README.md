# Brave Search

Web, news and image search through the Brave Search API.

## The key

**<https://api-dashboard.search.brave.com>** → sign in → **API Keys**. The free
plan gives a quota of queries a month; a card may be required to open it.

## Good to know

Every call counts as a query on the plan, whatever its size: the agent is told
to ask once with a good query rather than many narrow ones.

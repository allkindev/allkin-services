# Brave Search

Recherche web, actualités et images par l'API Brave Search.

## La clé

**<https://api-dashboard.search.brave.com>** → connexion → **API Keys**. Le
palier gratuit donne un quota de requêtes par mois ; une carte peut être
demandée pour l'ouvrir.

## Bon à savoir

Chaque appel compte pour une requête du forfait, quelle que soit sa taille :
l'agent a pour consigne de chercher une fois avec une bonne requête plutôt que
plusieurs fois avec des requêtes étroites.

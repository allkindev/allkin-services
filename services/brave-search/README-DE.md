# Brave Search

Web-, Nachrichten- und Bildersuche über die Brave Search API.

## Der Schlüssel

**<https://api-dashboard.search.brave.com>** → anmelden → **API Keys**. Der
kostenlose Tarif gibt ein monatliches Abfragekontingent; zum Freischalten kann
eine Karte verlangt werden.

## Gut zu wissen

Jeder Aufruf zählt als eine Abfrage des Tarifs, unabhängig von seiner Größe:
Der Agent soll einmal mit einer guten Abfrage suchen statt mehrmals mit engen.

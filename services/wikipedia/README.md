# Wikipedia

The articles of one language edition, through the MediaWiki API.

## The language

Enter the code of the edition: `fr`, `en`, `de`, `es`… One connection per
language; an agent that needs two editions gets two connections.

## Good to know

No key, but the API asks for a reasonable pace and refuses the biggest
requests (whole category dumps). An agent reads summaries, extracts and search
results; it does not edit.

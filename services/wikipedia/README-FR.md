# Wikipedia

Les articles d'une édition linguistique, par l'API MediaWiki.

## La langue

Saisis le code de l'édition : `fr`, `en`, `de`, `es`… Une connexion par langue ;
un agent qui a besoin de deux éditions reçoit deux connexions.

## Bon à savoir

Pas de clé, mais l'API demande un rythme raisonnable et refuse les requêtes
les plus lourdes (vidage de catégories entières). Un agent lit des résumés, des
extraits et des résultats de recherche ; il ne modifie rien.

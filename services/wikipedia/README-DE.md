# Wikipedia

Die Artikel einer Sprachausgabe über die MediaWiki-API.

## Die Sprache

Gib den Code der Ausgabe ein: `de`, `en`, `fr`, `es`… Eine Verbindung pro
Sprache; ein Agent, der zwei Ausgaben braucht, bekommt zwei Verbindungen.

## Gut zu wissen

Kein Schlüssel, aber die API erwartet ein vernünftiges Tempo und lehnt die
schwersten Anfragen ab (ganze Kategorien auf einmal). Ein Agent liest
Zusammenfassungen, Auszüge und Suchergebnisse; er bearbeitet nichts.

# Uptime Kuma

The state of your monitors, and your status pages.

## The key

**Settings → API Keys → Add API Key**. Enter any name and the key as the
password: Uptime Kuma reads the key, not the name. The address is the one of
the web interface.

## Good to know

The key only opens the metrics (what is up, what is down, response times,
certificate expiry); the status pages are public. Nothing can be changed
through this API: monitors are edited in Uptime Kuma. Version 2 or later.

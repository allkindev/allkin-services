# Uptime Kuma

El estado de tus monitores, y tus páginas de estado.

## La clave

**Ajustes → Claves API → Añadir clave API**. Introduce cualquier nombre y la
clave como contraseña: Uptime Kuma lee la clave, no el nombre. La dirección es
la de la interfaz web.

## Conviene saber

La clave solo abre las métricas (qué está en línea, qué no, tiempos de
respuesta, caducidad de certificados); las páginas de estado son públicas.
Nada se modifica por esta API: los monitores se editan en Uptime Kuma.
Versión 2 o posterior.

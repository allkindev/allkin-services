# Uptime Kuma

L'état de tes sondes, et tes pages de statut.

## La clé

**Paramètres → Clés API → Ajouter une clé API**. Saisis un nom quelconque et
la clé comme mot de passe : Uptime Kuma lit la clé, pas le nom. L'adresse est
celle de l'interface web.

## Bon à savoir

La clé n'ouvre que les métriques (ce qui est en ligne, hors ligne, les temps
de réponse, l'expiration des certificats) ; les pages de statut sont
publiques. Rien ne se modifie par cette API : les sondes s'éditent dans Uptime
Kuma. Version 2 ou plus.

# Uptime Kuma

Der Status deiner Monitore und deine Statusseiten.

## Der Schlüssel

**Einstellungen → API-Schlüssel → API-Schlüssel hinzufügen**. Einen beliebigen
Namen und den Schlüssel als Passwort eingeben: Uptime Kuma liest den
Schlüssel, nicht den Namen. Die Adresse ist die der Weboberfläche.

## Gut zu wissen

Der Schlüssel öffnet nur die Metriken (was läuft, was nicht, Antwortzeiten,
Zertifikatsablauf); die Statusseiten sind öffentlich. Über diese API wird
nichts geändert: Monitore werden in Uptime Kuma bearbeitet. Version 2 oder
neuer.

# Sonarr

TV series: the library, the calendar, what is missing, the download queue.

## The key

**Settings → General → Security → API Key** in Sonarr's interface. The address
is the one of the web interface (`http://host:port`), without `/api`.

## Good to know

The API is version 3. Deleting from the library and launching commands ask for your
confirmation in the conversation.

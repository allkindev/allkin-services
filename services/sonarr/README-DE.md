# Sonarr

Serien: die Bibliothek, der Kalender, was fehlt, die Download-Warteschlange.

## Der Schlüssel

**Settings → General → Security → API Key** in der Oberfläche von Sonarr. Die
Adresse ist die der Weboberfläche (`http://host:port`), ohne `/api`.

## Gut zu wissen

Die API ist Version 3. Löschen aus der Bibliothek und das Starten von Befehlen fragen
dich im Gespräch um Bestätigung.

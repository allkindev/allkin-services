# Portainer

Los entornos Docker a través de Portainer: contenedores, imágenes, stacks,
registros.

## El token

**Tu cuenta (arriba a la derecha) → My account → Access tokens → Add access
token**. La dirección es la de la interfaz de Portainer (`http://host:9000` o
`https://host:9443`).

## Conviene saber

El token actúa con tus permisos. Detener un contenedor y eliminar cualquier
cosa piden tu confirmación.

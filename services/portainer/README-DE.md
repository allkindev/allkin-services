# Portainer

Docker-Umgebungen über Portainer: Container, Images, Stacks, Logs.

## Das Token

**Dein Konto (oben rechts) → My account → Access tokens → Add access token**.
Die Adresse ist die der Portainer-Oberfläche (`http://host:9000` oder
`https://host:9443`).

## Gut zu wissen

Das Token handelt mit deinen Rechten. Das Stoppen eines Containers und jedes
Löschen fragen nach deiner Bestätigung.

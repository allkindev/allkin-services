# Portainer

Docker environments through Portainer: containers, images, stacks, logs.

## The token

**Your account (top right) → My account → Access tokens → Add access token**.
The address is the one of Portainer's interface (`http://host:9000` or
`https://host:9443`).

## Good to know

The token acts with your rights. Stopping a container and deleting anything
ask for your confirmation.

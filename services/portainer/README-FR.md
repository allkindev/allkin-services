# Portainer

Les environnements Docker par Portainer : conteneurs, images, stacks, journaux.

## Le jeton

**Ton compte (en haut à droite) → My account → Access tokens → Add access
token**. L'adresse est celle de l'interface de Portainer (`http://hôte:9000`
ou `https://hôte:9443`).

## Bon à savoir

Le jeton agit avec tes droits. Arrêter un conteneur et supprimer quoi que ce
soit demandent ta confirmation.

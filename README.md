# Allkin Services

Ready-made services for [Allkin](https://allk.in).

A service connects your agents to something outside Allkin — a website, an application, an
online account — so they can use it for you.

## Using one

In Allkin, open the **Services** page and press **Add a service**: the ones offered here are in
the list. Connect it with your own account, then give it to the agents that need it, from their
page.

An agent uses only the services you gave it.
